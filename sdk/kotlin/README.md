# FluxCast Kotlin SDK

Dependency-free FCDP v0.1 framing for JVM/Android projects. Secure-session
cross-language interoperability is intentionally not claimed yet.

The checked-in vector runner can be enabled with
`FLUXCAST_VERIFY_KOTLIN=1 bash scripts/verify_vectors.sh`. It has a 120-second
limit so a local compiler issue does not block the other SDK checks.
